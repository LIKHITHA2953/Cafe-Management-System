
# Cafe Management System ☕

## About the Project

This is a simple Cafe Management System developed using Python. It allows customers to view the cafe menu, select their favourite food items, and place orders.

The program checks whether the selected items are available and calculates the total bill based on the customer's order.

I created this project to practice Python basics and understand how dictionaries, conditional statements, user input, and arithmetic operations work in a real-time application.

## Menu

| Item | Price |
|---|---:|
| Pizza | 50 |
| Salad | 30 |
| Burger | 100 |
| Popcorn | 70 |
| Chicken Puff | 100 |

## Features

- Displays the available cafe menu.
- Allows customers to select food items.
- Checks item availability.
- Allows customers to add another item.
- Calculates the total order amount.

## Technologies Used

- Python

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run the following command:

   ```bash
   python cafe.py
   ```

4. Enter your food choices and view your total bill.
